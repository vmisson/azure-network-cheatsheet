# ☁️ Azure Network Cheatsheet

All Azure networking best practices, architecture guidance, SKU comparisons, and limits in one searchable static page.

🔗 **Live:** [https://network-cheatsheet.azure.cloud63.fr](https://network-cheatsheet.azure.cloud63.fr)

## What's inside

| Category | Sections |
|---|---|
| **Architecture & Topology** | Hub & Spoke Layout, Azure Virtual WAN, Hub vs vWAN Decision Matrix |
| **Network Foundations** | Subnet Sizing by Service, Subnet Delegation, NSG & UDR Compatibility, Routing with NVA |
| **Hybrid Connectivity** | VPN Gateway SKUs, ExpressRoute Components & SKUs |
| **Security** | Azure Firewall SKUs, Private Endpoint vs Service Endpoint |
| **Egress** | Outbound Internet & NAT Gateway Options |
| **Ingress & Exposure** | Application Gateway SKUs, Azure Front Door & DDoS Protection |
| **DNS** | Private DNS Zones, Private DNS Resolver Architecture |
| **Operations** | Day-2 Ops (monitoring, alerting, governance), Limits & Quotas, Best Practices |

## Features

- **Single static HTML page** — no framework, no build, no dependencies
- **185+ links** to official Microsoft Learn documentation
- **Search** — filter across all tables and cards instantly
- **Responsive** — works on desktop and mobile
- **Opinionated guidance** — practical recommendations, not just documentation summaries
